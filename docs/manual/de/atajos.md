# Tastenkürzel

Alle Tasten und Kombinationen des Programms, nach Seite. Die Tasten, die Sie selbst unter [Zuordnungen](mapeos.md#tastatur) zuweisen, und die Tastaturtasten der Tasten in der [SHOW](show.md#optionen-einer-taste) kommen hinzu. Eine unter Zuordnungen zugewiesene Taste hat Vorrang vor dem Tastenkürzel des Programms, das dieselbe Taste verwendet.

## Auf jeder Seite

| Taste | Was sie tut |
|---|---|
| **F1** | Live |
| **F2** | Show |
| **F3** | Programmieren |
| **F4** | Szenen |
| **F5** | Patch |
| **F6** | Fixtures |
| **F7** | Ausgänge |
| **F8** | Zuordnungen |
| **F9** | Optionen |
| **F10** | Playbacks |
| **F11** | Vollbild (und zurück zum Fenster) |
| **F12** | Öffnet dieses Handbuch auf der Seite, auf der Sie sind (auch die Taste **„?“** in der oberen Leiste) |
| **Strg+N** | Neue Show |
| **Strg+O** | Eine Show öffnen |
| **Strg+S** | Die Show speichern (beim ersten Mal wird nach einem Namen gefragt) |
| **Strg+Umschalt+S** | Die Show unter einem anderen Namen speichern („Speichern unter…“) |
| **Strg+B** | Blackout (ein und aus) |
| **Esc** | Alles stoppen. Im Lernmodus bricht es das ausstehende Bedienelement ab oder verlässt den Modus; bei aktiviertem „Aufnehmen“ unter Playbacks deaktiviert es die Aufnahme |
| **Strg+→** | Nächste Szene in jeder laufenden Gruppe |
| **Strg+←** | Vorherige Szene in jeder laufenden Gruppe |
| **G** | BeatGO (außer auf der Seite Show) |

Ist eine Seite gesperrt, fragt ihre Taste das Passwort ab (falls es eines gibt) und entsperrt. Bei gesperrter SHOW (Kiosk-Modus) funktionieren die Seitentasten nicht, und bei gesperrtem Setup auch nicht Strg+N, Strg+O und Strg+Umschalt+S.

T, G und die Tasten, die Sie unter Zuordnungen zuweisen, wirken nicht, während Sie in ein Textfeld schreiben, etwa in die Befehlszeile unter Programmieren.

## Playbacks

| Taste | Was sie tut |
|---|---|
| **Leertaste** | GO des ausgewählten Playbacks (ein GO pro Druck) |
| **Umschalt+Leertaste** | Zurück auf dem ausgewählten Playback |
| **Bild↑** | Vorherige Playback-Seite |
| **Bild↓** | Nächste Playback-Seite |
| **Esc** | Deaktiviert „Aufnehmen“ |

Sie funktionieren auf der Seite Playbacks, solange Sie nicht in ein Textfeld schreiben.

## Programmieren

| Taste | Was sie tut |
|---|---|
| Tippen | Was Sie auf der Seite tippen, geht in die Befehlszeile |
| **Eingabe** | Führt den Befehl aus |
| **↑** / **↓** | Die letzten Befehle |
| **Esc** | Leert die Befehlszeile (bei leerer Zeile: Alles stoppen) |

Siehe [die Befehlszeile](programar.md#befehlszeile).

## Show

| Taste | Was sie tut |
|---|---|
| Die Tastaturtaste einer Taste | Drückt diese Taste (solange Sie sie halten, wenn es eine Flash-Taste ist) |
| **Entf** / **Rücktaste** | Entfernt im Bearbeitungsmodus das Bedienelement der ausgewählten Zelle |
| **Esc** | Hebt im Bearbeitungsmodus die Auswahl auf |

## Superszenen

| Taste oder Geste | Was sie tut |
|---|---|
| **Leertaste** | Ab dem Cursor abspielen oder stoppen |
| **Entf** | Löscht den ausgewählten Block |
| **Strg+Mausrad** | Zoom auf der Zeitleiste |
| **Umschalt+Mausrad** | In der Zeit scrollen |
| Doppelklick auf das Lineal | Ab dort abspielen |

## Fader und Schieberegler

Nachdem Sie auf einen Fader oder Schieberegler geklickt haben:

| Taste oder Geste | Was sie tut |
|---|---|
| **↑** / **→** | Einen Schritt hoch |
| **↓** / **←** | Einen Schritt herunter |
| **Bild↑** / **Bild↓** | Zehn Schritte hoch oder herunter |
| Doppelklick | Setzt ihn auf seinen Ruhewert zurück (normalerweise null) |

## Cuelists und Schritte (Szenen)

| Taste oder Geste | Was sie tut |
|---|---|
| **Strg+Klick** / **Umschalt+Klick** | Wählt mehrere Cues oder Schritte aus, um ihre Zeiten gemeinsam zu ändern |
| Doppelklick auf einen Cue oder Schritt | Lädt ihn in den Programmer |
| Doppelklick auf die Nummer eines Cues | Ändert seine Nummer |
| Mausrad über einer angeklickten Zeit | ±0,1 s (mit **Umschalt** ±1 s) |
| **Esc** in einem Feld | Lässt den Wert, wie er war |

## Maus und Zusatztasten

| Geste | Wo | Was sie tut |
|---|---|---|
| **Alt+Klick** | Fast jedes Bedienelement | Bringt es auf die geöffnete SHOW-Seite |
| **Umschalt+Klick** | Lernmodus | Bedient das Bedienelement, statt es zuzuordnen |
| **Strg+Klick** | Flash-Tasten des Mischers | Lassen den Flash bis zum nächsten Klick eingerastet |
| **Strg+Klick** / **Umschalt+Klick** | Fixtures, Gruppen und 2D-Plan (Programmieren und Patch), Szenenliste | Fügt der Auswahl hinzu oder entfernt daraus |
| Mausrad | 2D-Plan | Zoom |
| Ziehen mit der rechten oder mittleren Maustaste | 2D-Plan | Verschiebt die Ansicht (Doppelklick: zentriert sie) |
| Rechtsklick | Taste 15° im 2D-Plan | Dreht andersherum |
| „Entsperren“ gedrückt halten | Gesperrte SHOW | Entsperrt |
