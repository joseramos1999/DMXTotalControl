# Scorciatoie da tastiera

Tutti i tasti e le combinazioni del programma, per pagina. I tasti che assegni tu in [Mappature](mapeos.md#tastiera) e i tasti della tastiera assegnati ai tasti dello [SHOW](show.md#opzioni-di-un-tasto) si aggiungono a questi. Un tasto assegnato in Mappature ha la precedenza sulla scorciatoia del programma che usa lo stesso tasto.

## In qualsiasi pagina

| Tasto | Cosa fa |
|---|---|
| **F1** | Live |
| **F2** | Show |
| **F3** | Programma |
| **F4** | Scene |
| **F5** | Patch |
| **F6** | Fixture |
| **F7** | Uscite |
| **F8** | Mappature |
| **F9** | Opzioni |
| **F10** | Playback |
| **F11** | Schermo intero (e ritorno alla finestra) |
| **F12** | Apre questo manuale alla pagina in cui ti trovi (anche il tasto **«?»** della barra superiore) |
| **Ctrl+N** | Nuovo show |
| **Ctrl+O** | Apri uno show |
| **Ctrl+S** | Salva lo show (la prima volta chiede il nome) |
| **Ctrl+Maiusc+S** | Salva lo show con un altro nome («Salva come…») |
| **Ctrl+B** | Blackout (accendere e spegnere) |
| **Esc** | Ferma tutto. Nella modalità Apprendi, annulla il controllo in sospeso o esce dalla modalità; con «Registra» armato in Playback, lo disarma |
| **Ctrl+→** | Scena successiva in ogni gruppo attivo |
| **Ctrl+←** | Scena precedente in ogni gruppo attivo |
| **G** | BeatGO (tranne nella pagina Show) |

Se una pagina è bloccata, il suo tasto chiede la password (se c'è) e sblocca. Con lo SHOW bloccato (modalità chiosco) i tasti delle pagine non funzionano, e con il Setup bloccato nemmeno Ctrl+N, Ctrl+O e Ctrl+Maiusc+S.

T, G e i tasti che assegni in Mappature non agiscono mentre scrivi in un campo di testo, come la riga di comando di Programma.

## Playback

| Tasto | Cosa fa |
|---|---|
| **Spazio** | GO del playback selezionato (un GO per pressione) |
| **Maiusc+Spazio** | Indietro sul playback selezionato |
| **PgUp** | Pagina di playback precedente |
| **PgDn** | Pagina di playback successiva |
| **Esc** | Disarma «Registra» |

Funzionano nella pagina Playback purché tu non stia scrivendo in un campo di testo.

## Programma

| Tasto | Cosa fa |
|---|---|
| Scrivere | Ciò che scrivi nella pagina va nella riga di comando |
| **Invio** | Esegue il comando |
| **↑** / **↓** | Gli ultimi comandi |
| **Esc** | Svuota la riga di comando (con la riga vuota, Ferma tutto) |

Vedi [la riga di comando](programar.md#riga-di-comando).

## Show

| Tasto | Cosa fa |
|---|---|
| Il tasto della tastiera di un tasto dello SHOW | Preme quel tasto (finché lo tieni premuto, se è flash) |
| **Canc** / **Backspace** | Nella modalità modifica, rimuove il controllo della cella selezionata |
| **Esc** | Nella modalità modifica, annulla la selezione |

## Super scene

| Tasto o gesto | Cosa fa |
|---|---|
| **Spazio** | Riproduce o ferma dal cursore |
| **Canc** | Elimina il blocco selezionato |
| **Ctrl+rotella** | Zoom sulla timeline |
| **Maiusc+rotella** | Spostarsi nel tempo |
| Doppio clic sul righello | Riproduce da lì |

## Fader e cursori

Dopo aver fatto clic su un fader o un cursore:

| Tasto o gesto | Cosa fa |
|---|---|
| **↑** / **→** | Sale di un passo |
| **↓** / **←** | Scende di un passo |
| **PgUp** / **PgDn** | Sale o scende di dieci passi |
| Doppio clic | Lo riporta al suo valore di riposo (di solito zero) |

## Cuelist e passi (Scene)

| Tasto o gesto | Cosa fa |
|---|---|
| **Ctrl+clic** / **Maiusc+clic** | Seleziona più cue o passi per cambiarne i tempi insieme |
| Doppio clic su una cue o un passo | Lo carica nel programmatore |
| Doppio clic sul numero di una cue | Ne cambia il numero |
| Rotella su un tempo premuto | ±0,1 s (con **Maiusc**, ±1 s) |
| **Esc** in un campo | Lascia il valore com'era |

## Mouse e modificatori

| Gesto | Dove | Cosa fa |
|---|---|---|
| **Alt+clic** | Quasi qualsiasi controllo | Lo porta nella pagina dello SHOW aperta |
| **Maiusc+clic** | Modalità Apprendi | Usa il controllo invece di mapparlo |
| **Ctrl+clic** | Tasti Flash del mixer | Lasciano il flash acceso fino al clic successivo |
| **Ctrl+clic** / **Maiusc+clic** | Fixture, gruppi e pianta 2D (Programma e Patch), elenco delle scene | Aggiunge o toglie dalla selezione |
| Rotella | Pianta 2D | Zoom |
| Trascinare con il tasto destro o centrale | Pianta 2D | Sposta la vista (doppio clic: la centra) |
| Clic destro | Tasto 15° della pianta 2D | Ruota nell'altro senso |
| Tenere premuto «Sblocca» | Show bloccato | Sblocca |
